# NARaz Android v0.2

Android WebView frontend, recreated from the supplied NARaz reference image: dark fintech UI, red pomegranate/NARaz identity, sidebar, dashboard, wallet/payments/academy/DApps/settings and responsive mobile navigation.

This is a frontend/testnet prototype. It does not contain real funds, private keys, a real blockchain or payment processing.

Build in Android Studio: Build → Build APK(s).
